# Source icons

The icons a cook can pick for a recipe source (a cookbook, a website, a channel).
From MingCute (https://github.com/Richard9394/MingCute), Apache License 2.0,
"line" style, via Iconify, like `../tag-icons`. Used as CSS masks, so the colour
comes from the text colour. The list the app offers is `SOURCE_ICONS` in
`backend/src/sources.ts` and `frontend/src/app/models.ts`; a file name here is
its id there.
